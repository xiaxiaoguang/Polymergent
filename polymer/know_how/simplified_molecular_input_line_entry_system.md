## Definition

SMILES (Simplified Molecular Input Line Entry System) is a line notation using short ASCII strings to describe chemical structures. It is a context-free language parsable by standard computational methods.

## Syntax

**Atoms:** Elements from the organic subset (B, C, N, O, P, S, F, Cl, Br, I) without formal charge and standard valence are written bare. All other atoms require brackets with explicit H count and charge notation (e.g., [NH4+] for ammonium, [OH-] for hydroxide). Example: water is O or [OH2].

**Bonds:** Adjacency implies single bonds; omit the "-" symbol unless clarity needed. Double (=), triple (#), and quadruple ($) bonds are explicit. A "non-bond" (.) indicates disconnected parts (e.g., [Na+].[Cl-] for aqueous NaCl).

**Branching & Cycles:** Parentheses denote branch points. Cycles are broken with numeric suffix labels.

## Canonical and Isomeric SMILES

Multiple valid SMILES strings can represent one molecule (e.g., CCO, OCC, C(O)C all represent ethanol). **Canonical SMILES** are unique strings generated by standardized algorithms (from Daylight, OpenEye, CDK, etc.), used for database indexing and uniqueness verification. **Isomeric SMILES** specify stereochemistry at tetrahedral centers and double bond geometry, enabling rigorous partial specification of chirality.

## Standards & Advantages

OpenSMILES (2007, Blue Obelisk community) is an open standard. SMILES is more human-readable than InChI and has extensive software support and theoretical backing (graph theory).
